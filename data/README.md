# Dataset provenance and use restrictions

The included `phishing.csv` has **11,054 rows**, a target named `class`, and 30 website predictors plus `Index`. The derived `phishing_processed.csv` is also checked into this repository.

- Likely original Kaggle dataset: https://www.kaggle.com/datasets/eswarchandt/phishing-website-detector (the exact source download/version is **not confirmed** by this repository).
- Related benchmark: https://archive.ics.uci.edu/dataset/327/phishing+websites (Mohammad and McCluskey, DOI: 10.24432/C51W2X). The UCI benchmark lists **11,055** instances, not 11,054. Its CC BY 4.0 terms **must not be transferred to an unverified Kaggle-derived copy**.
- The dataset download date, uploader license, version checksum, and whether downstream redistribution is authorized have **not been documented**. The presence of a public CSV is not evidence of permission to redistribute it.

**Outstanding action:** verify the Kaggle listing and original file terms against the exact source/version; if redistribution cannot be established, remove both dataset CSVs from the public repository and Git history as appropriate and provide authorized download/preparation steps instead. A normal Git delete does not purge past public history. Do not claim redistribution permission without evidence.

For local integrity tracking, run `sha256sum data/phishing.csv data/phishing_processed.csv` on your own copies and record the hashes alongside a verified download date/source. A hash alone cannot establish source attribution or rights.

The archived output metrics in `results/` came from an earlier experiment and are not regenerated by the smoke test.
